作業日誌 PWA 試作品
====================

このフォルダは、スマホ単体で使うオフライン対応の作業日誌試作品です。
元の作業日誌ファイルは変更しません。

機能
----
- 文章はスマホのキーボード音声入力で入力し、AI修正せず保存
- 日時を自動記録
- GPS緯度・経度を端末から取得して保存
- 畑Y・畑Kα・畑KΓの位置をそれぞれ一度登録し、GPSから畑名を判定
- オフライン時も端末内に記録を保存・検索
- 通信できるときに位置と日時から大まかな天気・気温を補完
- JSONバックアップ保存／復元

重要な注意
----------
1. PWAのGPS取得とオフライン起動には、HTTPSで最初に開き、アプリをインストールしてから使う方式を想定しています。
2. 初回はインストールとアプリ一式の読み込みのため通信が必要です。その後、アプリ本体と記録は端末内で動作します。
3. Androidの位置情報を許可してください。GPSが取れないときは位置なしでも記録保存できます。
4. 初回に畑Y・畑Kα・畑KΓのそれぞれの畑に行き、「今の位置を登録」を押してください。
5. 記録は端末内にだけ保存されます。ブラウザのデータを消すと失われる場合があるため、バックアップを保管してください。
6. 天気・気温の補完時だけOpen-Meteoへ位置座標と日時を送って気象データを取得します。作業内容の文章は送信しません。参考値であり、現地観測値ではありません。
7. HTMLを単にダウンロードしてChromeのダウンロード一覧から開くだけでは、PWAのインストールやオフラインキャッシュが成立しないことがあります。HTTPSの公開先を用意して、オンラインのうちにChromeから開いてインストールしてください。

ファイル
--------
index.html             アプリ本体
manifest.webmanifest   ホーム画面インストール情報
service-worker.js      オフライン用キャッシュ
icon-192.png           アプリアイコン（192px）
icon-512.png           アプリアイコン（512px）

HTTPS公開先について
-------------------
GitHub Pagesを無料で使う場合、GitHub Freeでは公開リポジトリが必要です。公開されるのはアプリのプログラムだけで、日誌データはこのアプリからアップロードしません。アプリのコードを公開したくない場合は、別の配布方法を検討してください。
